# zdev-skill

Agent skill for [zdev](https://github.com/5hanth/zdev) - multi-agent worktree development environment.

## What is this?

This is a skill package for AI coding agents (like [Clawdbot](https://docs.clawd.bot)) that teaches them how to use `zdev` for managing isolated development environments.

## Installation

Add to your agent's skills directory or reference directly.

## Usage

The skill provides `SKILL.md` which agents read to understand the zdev workflow:
- Starting/stopping features
- Working in isolated worktrees
- Managing ports and preview URLs
- Cleanup after PR merge
